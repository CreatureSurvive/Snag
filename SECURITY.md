# Security Policy

## Supported versions

Security fixes are released for the latest minor version.

## Reporting a vulnerability

Please don't open a public issue. Report it privately through
[GitHub's security advisories](https://github.com/CreatureSurvive/Snag/security/advisories/new),
with steps to reproduce and the affected version. You'll get a reply within a week, and a fix
will be released as soon as it's verified, with credit if you'd like it.
